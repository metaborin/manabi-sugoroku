# まなびの冒険すごろく

**1〜4人で力を合わせる、小学生向けの学習すごろく。** 同じ端末で交代しながら、動物たちのワゴンを進め、3びきの仲間を助けます。

**[ブラウザで遊ぶ](https://metaborin.github.io/manabi-sugoroku/)**

## 遊び方

1. 人数・各自のキャラクター・学年（1〜6年）を選びます。
2. 必要に応じて前学年の復習、習った単元を選びます。
3. サイコロ → 1マスずつ移動 → 国語か算数の1問 → 選んだ道のお話 → 次の人。
4. 4問ごとに仲間のもとへ到着。橋を直す、かごを届ける、灯りをともす3つのお手伝いをします。
5. 救助後は森か川の道を相談して選びます。12手番と3件の救助で、みんなでゴールします。

1人なら12問、2人なら各6問、3人なら各4問、4人なら各3問。1回5〜10分程度が目安ですが、回答タイマーはありません。サイコロは1〜3で、冒険開始時に決めた12回の出目合計がコースの長さになります。全員の出番を確保して、最後の回答まで遊べます。救助地点は各4手番の出目累計と一致します。

間違えても後退・休み・敗北はありません。ヒント、相談用の「たすけて」、再挑戦が使えます。2回間違えた後には答えと解説を見て進めます。「まだ ならっていない」で問題を無罰交換できます。分かれ道では道の形・地形・お話・救助方法が変わり、マスの数や問題数は変わりません。救助は大きなボタンで順に行う3段階のお手伝いで、失敗や時間制限はありません。

## 1.1の改善

- 森の小道／川の木道、木のトンネル／夕焼けの川沿いを選べる3章のマップ。
- 橋を修理、森の葉や川からかごを取り出し、ランタンで帰宅を案内する救助。
- サイコロの数だけ1マスずつ進むワゴン。助けた仲間は客車に乗ります。
- 今の手順・次のプレイヤー・救助までのマス数・章ごとの準備状況を表示。
- 確認済み25問に、10ます、同数のまとまり、分配、分数帯の図ヒントを追加。120問の問題文・正答・解説は初版から保持。
- 救助の途中も保存でき、初版で保存した続きも引き継げます。短いお祝いは動きを減らす設定に対応。

詳しくは [改善と確認の方針](docs/upgrade-notes.md) を参照してください。

## 教材範囲

**各学年：算数10問・国語10問、全120問。** 固定問題のみで、プレイ中のAI生成はありません。各教科2単元ずつの初版であり、全範囲や学校の授業順には対応していません。出題範囲・前提・公式資料・全問確認については [教材の確認記録](docs/curriculum.md) を参照してください。教員による監修や、児童が参加する学習効果検証は未実施です。

## 対応端末と使いやすさ

- Chrome/Edgeの現行ブラウザを想定。Chromebookの1366×768相当と狭幅のタッチ操作を検証。
- Lenovo IdeaPad Flex 3i Gen 8の実機では未検証です。
- マウス・タッチ・キーボード操作対応。文字入力不要。
- 効果音は初期状態でオフ。音量調整・短い演出・演出スキップあり。
- 読み上げは初期状態でオフ。端末に日本語のローカル音声がある場合だけ利用します。未提供・失敗時も文字で続行できます。
- 読みや文字表記そのものが出題対象の問題は、答えが漏れないよう読み上げを休止します。
- SVGとCSSで描画し、WebGL・外部画像・外部フォントは使いません。

## 保存とプライバシー

本名・生年月日・アカウントは不要です。ゲーム状態は通常メモリだけに保持します。「ここまでを ほぞん」を押すと、学年・キャラクター・単元・進行状況を**このブラウザのlocalStorage**に保存します。保存は1枠で、次の保存で上書きします。自動保存ではありません。ブラウザのデータ削除やシークレットモード終了で失われる場合があります。設定から保存データを消せます。

1.1は救助の途中も保存します。初版の保存形式も読み込み、すでに助けた仲間・設定・手番を保持して再開します。

休憩・戻る操作では進行を保持し、最初からやり直す前には確認します。ページ終了時はブラウザの終了確認を利用しますが、OSの強制終了等は検知できないため、閉じる前に保存してください。

分析ツール、広告、プレイ記録のアップロード、外部API、課金機能はありません。読み上げでも外部音声サービスを呼びません。ホスティングサービスであるGitHub Pagesにページや静的ファイルを取得する通常の通信は発生します。

## 開発

Node.js 24 / npm。React・TypeScript・Viteで作成した静的サイトです。

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
```

WindowsのE2Eはインストール済みEdgeを使用します。CIではChromiumを使用します。`src/engine.ts` はゲームのルールと状態遷移、`src/questions.ts` は教材データ、`src/Art.tsx` はオリジナルSVGです。出題とルールを分離し、将来の教科・モード追加に備えています。現在は協力型のみです。

`main`へのpushでlint・型検査・全問検査・エンジン検査・ブラウザ検査・buildを実行し、すべて成功した場合だけGitHub Pagesへ公開します。
