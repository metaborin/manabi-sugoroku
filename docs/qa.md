# 初版の検証記録

2026-10-03、Windows上のNode.js 24.16.0とEdgeで検証しました。公開先のGitHub Actionsでは同じ検査をLinux / Chromiumで実行し、成功したビルドだけをPagesへ配信します。

## 自動検証

- ESLint、TypeScript、Vite production build。
- Nodeテスト19件：状態遷移14件と問題庫5件。
- 問題120件の件数・ID・メタデータ・選択肢・正答・ヒント・解説を点検。算数60件を別式で再計算、国語60件を別の正答一覧と照合。漢字の学年配当と音声抑止も検査。
- ブラウザ9シナリオ：1人、2人（2・6年）、4人（1・6・3・5年）の12手番完走と再プレイ、誤答・ヒント・相談・未習交換・解説、分岐と3救助。
- 実際のダブルクリック、戻る操作、休憩、やり直し取消、保存・再読み込み、単元選択と前学年復習。
- 読み上げオフ・API非対応でも継続。初期状態の無音を確認。
- ページとアセットの失敗なし、アプリからの外部リクエストなし、未処理JavaScript例外なし。

## 目視・操作確認

1366×768（Chromebook相当）と390×844（タッチ）で確認。マップ・選択肢・操作ボタンに重なりはなく、横方向のはみ出しはありません。狭い画面では縦にスクロールして遊びます。キャラクター・道・ワゴン・救助目標はオリジナルSVGです。

画面記録はローカルの `artifacts/` に出力します。テスト成果物やゲームの保存データはリポジトリに含めません。

## 残る制限

- Lenovo IdeaPad Flex 3i Gen 8の実機では未検証。
- 実児童による操作・学習効果検証、教員監修は未実施。
- 教材は各学年の一部単元。全教科・全範囲には対応しません。
- 日本語のローカル音声がない端末では読み上げできません。
- OSの強制終了やブラウザ保存領域の削除からは復元できません。明示保存は1枠です。
