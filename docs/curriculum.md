# 初版の問題範囲と確認記録

これは継続収録する既存120問の確認記録です。現在の作業ブランチの360問については [追加240問の記録](question-expansion.md) を参照してください。

1.1では確認済み120問を保持し、25問の算数に図ヒントを追加しました。対象・独立検査・図の方針は [1.1の改善記録](upgrade-notes.md) に記載しています。

このゲームは国語・算数の一部を楽しく復習するための初版です。各学年20問（算数10問・国語10問）、合計120問を固定データとして収録しています。各教科は2単元、各単元5問です。教科書の全単元、学校の年間進度、個々の児童の履修状況を保証するものではありません。教師による教材審査・児童参加の学習効果検証は未実施です。

## 収録範囲

| 学年 | 算数（各5問） | 国語（各5問） |
| --- | --- | --- |
| 1 | 10までの加法／減法（0を含む） | 仮名・助詞の表記と語のつながり／文脈付き漢字読み |
| 2 | 2桁の加減（繰上り・繰下りあり）／九九 | 文脈付き漢字読み／語彙の仲間・反対語 |
| 3 | 余りのない除法／時刻・時間・秒 | 文脈付き漢字読み／主語と述語 |
| 4 | 百分の一までの小数加減／同分母の真分数加減 | 文脈付き漢字読み／接続語の働き |
| 5 | 小数×小数・小数÷小数／異分母分数の加減 | 文脈付き漢字読み／日常の敬語 |
| 6 | 分数の乗除／整数の比 | 文脈付き漢字読み／短文の主張・理由・目的 |

国語の漢字以外の配当は、学習指導要領の「1・2年」「3・4年」「5・6年」のまとまりから初版用に割り振ったものです。3年の主語・述語や4年の簡単な同分母分数には、前学年の復習を含みます。6年の読解も短い導入・復習問題に限定しており、本格的な長文読解全体を扱いません。

## 出題と読み上げの方針

- 各問に `grade`、`subject`、`unit`、`prerequisite`、`answer`、`hint`、`explanation`、`speech`、`speechSafe`、`audit` を持たせています。学年を選んだだけで「習った」とは扱いません。遊ぶ前の単元選択、前学年の復習、無罰の問題交換を利用できます。
- 本文・選択肢・ヒントは、出題対象の漢字以外を原則かな表記にしました。漢字読み30問は短い文で意味を限定します。同じ読みの正答候補や、正答と同値の分数を同時に置きません。
- 漢字読み30問と仮名・助詞の表記4問は `speechSafe: false`。音声用データも中立の案内だけにして、問題全文を音読して正答を明かさないようにしています。他の86問にも独立した音声用の読みを用意しています。
- プレイ中のAI出題や外部教材取得はありません。データは固定の120問だけです。配列を組み立てる関数は共通メタデータの付与と正答の位置照合のみを行います。

## 全問確認

2026-10-03に全120問の問題文・正答・ヒント・解説を点検しました。`audit` は各問を別の計算・逆算・文法上の役割・文中の根拠で確認した保守用メモで、ゲーム画面には出しません。別のレビュー担当も全120問を独立読了し、答え・選択肢・読み上げ・学年範囲を再確認しました。

機械点検では、120件のID一意性、6学年×2教科×10問、24単元×5問、必須項目、3択の文字列重複、正答位置を確認しました。算数60問の正答は独立した計算結果と照合し、分数・比・時刻を数値化して全選択肢の値の重複がないことも確認しました。国語60問は独立した正答リストとの照合に合格しました。対象漢字以外の学習者向け本文にルビ無し漢字が残っていないことも検査しました。構造チェックだけで内容を正しいと判定せず、文面の読了と合わせています。

これらの自動検査は `tests/questions.test.ts` の5テストとして保存してあり、`npm test` で再実行できます。正答データとは別に、算数の独立した計算式と国語の確認済み正答リストを保持しています。漢字は実際に使う字だけの学年配当表もテスト内に持ち、意図しない上位学年字への変更を検出します。問題庫とこのテストに対するTypeScript・ESLint検査も成功しました。

今後、理科・社会・生活・外国語などを加える場合は、問題データを追加するだけでなく、各教科の配当と前提を別途確認します。初版は国語・算数のみです。
