# 360問への教材拡充（ローカル検証版）

2026-10-04。公開済み `fad9f51` の120問に、各学年・各教科20問ずつ、計240問を追加します。各学年は算数30問・国語30問、合計360問です。学年×教科ごとに6単元、各5問、全72単元群です。このブランチは未公開です。

## 広げた範囲

既存の計算、漢字読みなど120問はIDを含む全フィールドを保持しています。下表は新しく加えた範囲で、各欄20問です。

| 学年 | 追加した算数 | 追加した国語 |
| --- | --- | --- |
| 1 | 数順・数え方、10のまとまり、形、長さ・広さ・かさの比較 | 仮名表記、名前と動き、挨拶と丁寧語、短い話 |
| 2 | 1000までの数、三角・四角・箱、長さの単位、時間の単位 | 語彙、文を整える、順序、話の重要情報 |
| 3 | 万の位、乗法、長さと重さ、円と三角形 | 指示語、接続語、修飾語、理由と気持ち |
| 4 | 概数、面積、角度、二つの観点による分類 | 指示語、段落のつながり、ことわざ・慣用句、物語の変化 |
| 5 | 倍数と約数、体積、平均、割合と百分率 | 事実と意見、文章の構成、比喩と反復、語の意味 |
| 6 | 円の面積、角柱・円柱の体積、比例・反比例、中央値・最頻値 | 意見と根拠、二つの情報、表現と推敲、場面に合う敬語 |

数字の置換だけで増やさず、形の特徴・比べ方・情報の関係・短い文章の根拠などを加えました。本文はオリジナルです。算数の図形問題も、図を見ないと条件が不足する問いにはしていません。

## 学年配当と前提

- [文部科学省の公式入口](https://www.mext.go.jp/a_menu/shotou/new-cs/1387014.htm)
- [算数解説](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)：冊子42–43頁の計算配当、57・60頁の測定と単位、62頁の割合・比例など。個別範囲は1年78・88–92頁、2年104・118–125頁、3年136・142–144・158–165頁、4年181–224頁、5年234–276頁、6年286–314頁を参照。
- [国語解説](https://www.mext.go.jp/content/20220606-mxt_kyoiku02-100002607_002.pdf)：冊子198・200頁の系統表、学年帯別の本文41・76・115頁以降を参照。表記・語彙・文・情報の関係・敬語等を照合。

国語の多くは1–2／3–4／5–6年の学年帯で示されています。漢字等の明示配当を除き、帯の内容をゲーム内の各学年へ割り振るのは本プロジェクトの設計です。前学年内容の復習も含みます。文部科学省の認定や監修を意味しません。

各問に学年、教科、単元、前提、正答、ヒント、解説、読み上げ用の読み、点検根拠を保持します。学年だけで履修済みとは判定しません。前学年復習、習った単元の選択、無罰の問題交換を引き続き利用できます。全単元・年間進度への対応をうたうものではありません。

出題漢字以外の本文・選択肢・ヒント・解説はかな中心です。文字表記や漢字の読み自体を問う問題は、読み上げを止め、中立の音声案内のみをデータに持たせています。新問も固定データで、実行中の生成や外部取得はありません。

## 互換性と出題

既存120問は `src/questions-legacy.ts` にそのまま保存し、追加を4モジュールに分離しました。旧データ全体のSHA-256をテストで固定し、IDだけでなくヒント・解説等も変更されていないことを確認します。

旧保存の読み込みでは、明示した既知の旧問題庫と照合し、現在も全ての旧内容が保持されている場合のみ受理します。現在問題、試行回数、ヒント、出目、各人のデッキ順、進行を保持します。旧「全単元」は当時の単元一覧へ固定し、再プレイでも未選択の新単元を勝手に出題しません。新単元は設定から追加できます。不明な署名や改変したデッキ、不整合な状態は引き続き拒否します。

各人は、自分にまだ出ていない問題を優先します。問題を交換した場合も、その問題は出題済みとして扱います。国語・算数の交互出題と、選んだ単元を優先します。同じ教科に未使用の候補が複数ある場合は、直前の仲間と同じ問題を避けます。候補が1問しかない場合も進行を止めません。全員同学年4人×6学年×100種の固定seedでは、隣接する仲間への同問題が旧ルール618/6600回から0/6600回になりました。個人未使用を優先するため、どんな条件でも重複ゼロを保証する機能ではありません。
