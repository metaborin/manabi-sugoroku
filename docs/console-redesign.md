# ゲームの舞台としての画面再設計

この変更は**ローカルレビュー用**です。push・deploy・公開更新は行わず、公開中の1.3とREADMEの説明は変更していません。以下は実装内容とローカル検証の記録であり、公開完了の記録ではありません。

## 画面の変化

1.3は地図・問題カード・章一覧・参加者一覧・保存欄を同じページに並べる構成でした。今回は森の景色を舞台にし、現在の操作に合わせて場面を切り替えます。1366×768では舞台と操作を見渡せる配置を目指し、狭幅では文章や選択肢を切らずに縦へ並べます。

| 場面 | 1.3 | 今回のローカル実装 |
| --- | --- | --- |
| タイトル | 説明と準備欄へ続くトップページ | 森・動物・ワゴンを大きく見せ、「はじめから」「つづきから」を選ぶ場面 |
| 仲間のキャンプ | 人数分の設定カードを同時表示 | 動物のスロットを選び、1人ずつ共通の編集パネルで設定 |
| 探索 | 地図の横に手番カード、下に進行情報 | 地図を主役にし、サイコロ・確定した目・移動数・次の操作を下の操作帯へ配置 |
| 問題 | 地図の横の問題カード | 専用の手帳に問題文、考える手がかり、選択肢を表示。ヒント・相談・交換をまとめる |
| 解説 | 選択肢の下に答えと説明 | 仲間の反応と答え・解説を中心にした場面。既存の図による確認も保持 |
| 出来事・救助・分岐 | 右側のカード内で表示 | 大きな絵と短い台詞、現在のお手伝い一つを表示。救助後は道選びへ切り替える |
| 結果 | 右側のカードでお祝い | ワゴンと仲間のお祝い、救助・通った道・全員の学びを振り返る手帳 |

手番の番号・学年・個人の何問めか、現在の章と救助数、設定・休憩を上部にまとめています。詳しい参加記録と保存操作は休憩メニューへ移し、保存した続きは再開前の専用画面で確認します。問題や操作ボタンを地図の道に重ねない構成です。

## 保持する教材とルール

- 同じ端末で1〜4人が交代する協力型、小学1〜6年の個別設定を保持します。
- 固定120問とゲームエンジンを変更せず、学年・前学年復習・選択単元による出題を維持します。問題数や学習範囲は増やしていません。
- サイコロの確定した目に合わせた移動、12手番の参加配分、分岐と救助、手番トークンによる進行制御を保持します。
- 誤答への罰は設けず、ヒント・相談・再挑戦・答えと解説・未習問題の交換を維持します。
- 同じ保存キーとversion 2形式、初版version 1の読み込みを保持します。保存は端末内1枠への明示操作のままで、本名・アカウント・外部へのプレイ記録送信は不要です。
- 短縮演出・スキップ・端末の「動きを減らす」、保存サマリー・未保存表示・消去確認、キーボードでのダイアログ操作を引き継ぎます。

## 描画と音

追加の森やタイトルのワゴンはオリジナルのSVGとCSSで描画します。WebGLや画像・音声配信サービスは使いません。任意の短い効果音はWeb Audioで端末内生成し、初期状態はオフです。音声機能が使えなくてもゲームを続けられます。読み上げは従来どおり端末内の日本語音声のみで、出題対象の読みや表記を漏らさない制約を保持します。

主な実装は `App.tsx` の場面切り替え、`console.css` の舞台配置、`PartySetup.tsx` の仲間選択、`WorldScenery.tsx` の景色、`useGameAudio.ts` の効果音です。依存パッケージの追加はありません。
